Cómo crear el acceso de César — 3 pasos · ~3 min

Lo más rápido es hacerlo manual desde Supabase Dashboard (sin deploys, sin esperar build de Vercel).

  1. Crear el usuario en Auth.
    Supabase Dashboard → Authentication → Users → Add user → Create new user.
    · Email: cesar.acerosaranda@gmail.com (su correo real)
    · Password: liftory123 (temporal, él lo cambia después)
    · Marca Auto Confirm User (skip email confirmation).
  2. Correr este SQL en SQL Editor para asignarle programa, completar onboarding y agregar a VIP. Reemplaza 'cesar.acerosaranda@gmail.com' y 'César':
    DO $$ DECLARE v_user_id uuid; v_template_program_id uuid; v_mesocycle_id uuid; BEGIN -- 1. Find user by email SELECT id INTO v_user_id FROM auth.users WHERE email = 'cesar.acerosaranda@gmail.com'; -- 2. Find live M2 mesocycle of BUILD HIM ELITE SELECT m.id, m.template_program_id INTO v_mesocycle_id, v_template_program_id FROM mesocycles m JOIN programs p ON p.id = m.template_program_id WHERE p.name = 'BUILD HIM ELITE' AND m.status = 'live' AND m.cycle_number = 2; -- 3. Create / update user_profile (mark onboarding complete) INSERT INTO user_profiles (user_id, full_name, gender, experience_level, onboarding_completed) VALUES (v_user_id, 'César', 'male', 'intermediate', true) ON CONFLICT (user_id) DO UPDATE SET full_name = EXCLUDED.full_name, onboarding_completed = true; -- 4. Activate VIP subscription (free annual) UPDATE user_profiles SET subscription_status = 'active', subscription_tier = 'annual', current_period_end = (now() + interval '1 year') WHERE user_id = v_user_id; -- 5. Assign BUILD HIM ELITE M2 program INSERT INTO programs (user_id, name, total_weeks, current_week, current_block, is_active, mesocycle_id) SELECT v_user_id, name, total_weeks, 1, 'accumulation', true, v_mesocycle_id FROM programs WHERE id = v_template_program_id; -- 6. Workouts get propagated automatically by the propagate_template_sets() trigger. END $$;
  3. Agregar su email a VIP_EMAILS en código (1 archivo, 1 línea — luego push):
    // src/pages/Onboarding.tsx (línea 43) const VIP_EMAILS = new Set([ "victor.vega.0495@gmail.com", "cesar.acerosaranda@gmail.com", // ← añadir ]); // supabase/functions/activate-vip/index.ts (línea 11) const VIP_EMAILS = new Set([ "victor.vega.0495@gmail.com", "cesar.acerosaranda@gmail.com", // ← añadir ]);
    Es opcional para César porque su subscription ya queda activa por SQL — pero si hace logout y vuelve, el VIP_EMAILS list le da el feel de "founding".

Cómo se conecta esta WelcomeCard al flow real

Esta card NO es el Step 11 de Onboarding (porque César skipea Onboarding). Necesita un trigger nuevo en Home.tsx:

  • Cuando César hace login por primera vez → Home detecta que es VIP-joiner-no-Onboarding (flag o check de localStorage vip_welcome_seen_M2_<userId> + check VIP_EMAILS).
  • Reusa el componente MesocycleWelcomeCard con un nuevo prop variant: "vip-joiner".
  • El password hint solo aparece en variant vip-joiner.

Implementación = 1 prop nuevo + el copy variant. ~30 min de codeo + commit + push.
