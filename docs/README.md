# docs/

Documentos internos: propuestas de diseño, auditorías, exploraciones de marca
y los entregables en HTML de cada sesión.

**Esta carpeta NO se sirve.** Vivían en `public/`, que Vercel publica en la raíz
del dominio — cualquiera con la URL podía abrir `liftory.app/ux-audit-report.html`
o descargar los PDFs de marca. Se movieron aquí el 21 de octubre de 2026.

Para abrir alguno, ábrelo directo desde Finder (doble clic) o arrastra el
archivo al navegador. No hace falta el servidor de desarrollo.

En `public/` solo deben quedar assets que la app pide en runtime: iconos,
`manifest.json`, `robots.txt` y `liftory-logo-email.png` (los correos lo
apuntan a `https://liftory.app/liftory-logo-email.png`, así que ese no se
puede mover).
