# Target Athlete · BUILD HIM ELITE

## Quién es

Hombre. 25-45 años. Quiere físico estético **+ función**. Lo atraen los Marcus Filly, Brian Pruett, Colin Pasque — hybrid athletes.

NO es:
- ❌ Powerlifter puro (no busca 1RMs)
- ❌ Bodybuilder puro (no busca solo hipertrofia con curl bro routines)
- ❌ Crossfitter (no busca metcons random sin progresión estructural)
- ❌ Influencer (no busca el "trend lift" del mes)

ES:
- ✅ Tipo que quiere verse mamado **y** poder subir escaleras de 8 pisos sin morir
- ✅ Quiere ser "indestructible" — tendón resistente, postura erguida, grip firme
- ✅ Aprecia técnica, tempo, programación honesta

## Lo que el atleta quiere lograr (cita Andoni)

1. **Hombros sólidos 3D** (3 cabezas: anterior + lateral + rear delt)
2. **Espalda amplia (V-taper)** — lats wide, posterior chain visible
3. **Cintura pequeña**
4. **Piernas y glúteos trabajados**
5. **Abs definidos**
6. **Movimiento como pulso de testosterona → vitalidad + libido**
7. **Sentirse atlético e indestructible**

## Cómo se traduce en programación

| Target | Implementación obligatoria |
|---|---|
| **Hombros 3D** | Trabajar en TODOS los días posibles: lateral raise + rear delt + OHP + pike + handstand prep. Mínimo 2 días/semana con shoulder dedicated. |
| **V-taper** | Wide grip pull-ups, dead hangs, scap work, straight-arm pulldowns tempo. Lat volume protagonista mínimo 1 día/sem. |
| **Cintura pequeña** | **CERO rotacional con peso pesado** (oblicuos con DB pesado ensanchan la cintura). Anti-rotation sí (Pallof, Renegade Row, Suitcase Carry). Hanging Knee Raises sí. Russian Twist con DB **NO**. |
| **Glúteo** | Triple frecuencia semanal — heavy bilateral (Smith HT / Hip Thrust) + single-leg (Bulgarian / RDL unilateral) + integrated (Walking Lunges, Carries). |
| **Abs visibles** | Hollow body, dragon flag progression, L-sit, hanging work. NO machine crunches. |
| **Testo pulse** | Heavy compound (squat / DL / OHP) + sprints + EMOM density brief + plyometric. CNS recovery REAL (no fake). |
| **Indestructible** | Tendón work (Nordic, Reverse Nordic, eccentric overload) + ankle/knee/hip/shoulder prehab + Loaded Carries semanales. |

## Equipamiento que asumimos disponible

- Barbell (olímpica)
- Smith machine
- DBs (hasta pesado: 50kg+)
- KBs (variedad de pesos)
- Cable machine (cross-over, pulley)
- Pec deck (o reverse fly machine)
- Leg press
- Sled (con tracción y resistencia)
- Banco regulable
- Pull-up bar (con rings)
- Bandas elásticas

Si el spec dice "home gym" o "limited equipment", **adaptar**:
- KB-only meso usa solo KB
- Bodyweight meso reemplaza heavies por skill calistenia (handstand, MU, dragon flag, planche)

## Programas futuros que vendrán

### Programa para mujeres (BUILD HER ELITE)

Targets distintos:
1. Glúteo (prioridad 1 — frecuencia 4x/sem)
2. Hombros redondeados (lateral + posterior, sin volumen anterior excesivo)
3. Piernas tonificadas
4. Espalda + brazo definidos
5. Postura erguida + abs definidos

Implementación: igual filosofía hybrid, prioridad invertida. Bulgarian + Hip Thrust + RDL + Cable Pull-Through + Lateral Raise + Lat Pulldown protagonistas.

### Programas de frecuencia reducida (3 días, 4 días/sem)

| Frecuencia | Estructura recomendada |
|---|---|
| 6 días | Push / Pull / Legs / Hybrid / Skill / Active recovery (M3 actual) |
| 5 días | Push / Pull / Legs / Hybrid / Skill |
| 4 días | Upper push / Upper pull / Lower / Hybrid Conditioning |
| 3 días | Full body A / Full body B / Hybrid (todo full body con énfasis rotativo) |

Sin bajarse de calidad. Si son 3 días, cada uno tiene más bloques (4-5 lifts vs 3). El volumen semanal target se mantiene.
